# Reusable UI Readiness Checklist

Use for shared UI components.

- [ ] Component purpose is defined.
- [ ] Package/location is identified.
- [ ] Props/API are documented.
- [ ] Rendered states are documented.
- [ ] Events/callbacks are documented.
- [ ] Accessibility contract is documented.
- [ ] Styling/theming constraints are documented.
- [ ] Composition rules are documented.
- [ ] Required unit/component tests target the documented component API.
- [ ] Browser automation need is explicitly accepted or rejected with a reason.
