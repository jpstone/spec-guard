# API Contract Readiness Checklist

Use for reusable non-UI APIs.

- [ ] API purpose is defined.
- [ ] Package/module location is identified.
- [ ] Exported surface is listed.
- [ ] Inputs and outputs are specified.
- [ ] Error behavior is specified.
- [ ] Side effects are specified.
- [ ] Security/tenant rules are specified, if applicable.
- [ ] Versioning/backward-compatibility expectations are stated.
- [ ] Required unit tests target only the documented/exported API surface.
