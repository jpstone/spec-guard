# Document Deliverable Readiness Checklist

Use only when the document itself is the deliverable.

- [ ] Audience is identified.
- [ ] Purpose is defined.
- [ ] In-scope and out-of-scope content are defined.
- [ ] Required sections are listed.
- [ ] Required procedures, decisions, or policy gates are listed.
- [ ] Acceptance criteria are defined.
- [ ] Process/document checks are identified.
- [ ] Review or approval requirements are identified.
- [ ] Checks are not being used as a substitute for product behavior tests.
