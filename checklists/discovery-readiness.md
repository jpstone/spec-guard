# Discovery Readiness Checklist

Use before answering "what did we miss?" or similar discovery prompts.

- [ ] Human explicitly requested discovery.
- [ ] Discovery scope is clear.
- [ ] Discovery type is clear: security, legal, accessibility, reliability, product, tests, technical debt, or other.
- [ ] Findings will be evidence-based, not invented feature ideas.
- [ ] Findings will distinguish risks/gaps from optional enhancements.
- [ ] Findings will state whether each item is required for the current spec.
- [ ] No implementation will happen unless separately authorized.
- [ ] Follow-up work will be recorded as specs, blockers, or scope discoveries.
