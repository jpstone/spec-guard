# Failure-First Checklist

Use after writing tests and before implementation.

- [ ] New test was written before implementation.
- [ ] Test validates behavior, contract, or user-visible outcome.
- [ ] Test does not validate prose unless the document is the deliverable.
- [ ] Test avoids private/internal implementation details.
- [ ] Test was run before implementation.
- [ ] Test failed for the expected reason.
- [ ] If the test could not be run, the concrete reason is recorded.
