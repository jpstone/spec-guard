# UI Readiness Checklist

Use before any UI implementation.

- [ ] Feature spec is identified.
- [ ] Human-provided mockup, wireframe, or explicit design direction is available.
- [ ] Component library reference is available.
- [ ] Accessibility expectations are defined.
- [ ] Automation expectations are defined.
- [ ] UI is classified as reusable component or one-off application UI.
- [ ] Placeholder UI is not planned unless explicitly authorized by a human.
- [ ] Missing UI inputs are documented as blockers before halting.
