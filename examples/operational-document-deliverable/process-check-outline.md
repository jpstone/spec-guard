# Process Check Outline

Write before drafting or finalizing the runbook:

```text
runbook includes required sections
runbook identifies when rollback is appropriate
runbook names required access/permissions
runbook includes rollback procedure
runbook includes verification steps
runbook includes escalation path
```

## Expected Initial Failure

The runbook does not exist or lacks required operational sections.

## What Not To Do

- Do not replace product behavior tests with document checks.
- Do not use this exception for normal feature implementation.
- Do not check arbitrary wording unless exact wording is required by policy/legal/compliance.
