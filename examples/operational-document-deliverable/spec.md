# Spec: Deployment Rollback Runbook

## Goal

Create an operational runbook that explains how to roll back a failed production deployment.

## Expected Behavior

The deliverable is the document itself. It must give operators enough information to identify the failed deployment, execute rollback, verify recovery, and escalate if needed.

## Classification

Operational/document deliverable.

## Required Tests / Checks

Process/document checks are appropriate because the document is the deliverable.
